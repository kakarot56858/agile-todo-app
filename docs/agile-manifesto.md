# How This Project Follows the Agile Manifesto

| Manifesto value or principle | How I applied it |
|---|---|
| Individuals and interactions over processes and tools | Daily standup notes and discussion in issues |
| Working software over comprehensive documentation | A working app was delivered at the end of each sprint |
| Customer collaboration over contract negotiation | Customer feedback in the Sprint 1 review became issue #6 |
| Responding to change over following a plan | Due dates were added in Sprint 2 although not in the original plan |
| Deliver working software frequently | Two sprints, each with a working version, plus tagged releases |
| Simplicity | Built a small app with only the features users need |
| Regular reflection and improvement | Retrospective after every sprint |
