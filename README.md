# Agile To-Do App

A simple student to-do list built to demonstrate the Agile Manifesto principles.

## Agile approach
- 2 sprints tracked with GitHub Milestones
- User stories as GitHub Issues
- Progress tracked on a GitHub Projects board
- Standups, reviews and retrospectives in the `docs/` folder
- See `docs/agile-manifesto.md` for how each principle was applied

## Features
- Add, complete and delete tasks
- Due dates
- Clean styling
